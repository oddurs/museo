01 Identity

The identity is typographic, so the mark is not drawn — it is Whitney's own M, lifted out of the font file by scripts/build-mark.py and written as an SVG path. Change the weight or the letter there and the mark follows the type, because it is the same outline the wordmark is set in.

Mark

Whitney Bold — the wordmark's own weight — which holds its counters at 16px. The cap sits on an optical centre, not a mathematical one. Reverse it on a dark or busy ground; never on another color.

Whitney Bold, uppercase, set tight. Bold is what lets it be small: at 30px it holds a masthead that Light needed 54px to hold, so the furniture around it gets to be light.

Not this

Four ways the identity stops being itself.

  • Do not set the wordmark in another face, or in another weight of Whitney.
  • Do not letterspace it by eye — the two values are tokens.
  • Do not put the mark and the wordmark in a lockup. They do separate jobs: the mark is for a tab or an app icon, the wordmark for a page.
  • Do not add a second color. Vermilion is the identity; anything else is decoration.

02 Principles

  1. One

    Systems before screens. The ramp, the scale and the figure sets were settled and measured before a single component was composed. Nothing in app.css holds a raw value; if it does, that is a bug in the system rather than a shortcut in the page.

  2. Two

    One color, and it must earn its place. Vermilion marks the keyline, the current selection, the pins and focus — the things you act on. It is never decoration, and there is never a second accent.

  3. Three

    Twelve grays, because detail needs range. Hairlines, marks and text each get their own steps. Borrowing one value for two jobs is what makes an interface look approximate.

  4. Four

    Set the type, don't just style it. True small caps, old-style figures in prose, lining tabular figures in columns, the real ordinal glyph. These are the differences between type that is set and text that is typed.

  5. Five

    Rules and whitespace instead of boxes. No radius, no shadow, no gradient, and nothing moves on selection — weight and color carry it.

03 The neutral ramp

Neutral and barely cool. The warm ramp this replaced read as parchment and dated the whole page. Ratios are measured against --paper in the browser. The 4.5:1 line falls between 400 and 500, and that is the hard floor for text.

    04 The primary

    Vermilion. One hue, in two values for two jobs. --primary is 3.57:1 on paper — enough to draw with, not enough to read at 11px — so the pins, keyline and markers use it, and anything set in the accent uses --primary-ink at 4.96:1. Marks draw; text speaks.

        07 Scale

        Eight sizes, spaced by eye rather than by ratio. A strict modular scale put a museum's name and its address too close together; the interval from --size-heading to --size-small is deliberately wider than a ratio would give, and it is the most important one in the system.

            10 The index entry

            The application's one composite component: a catalogue row, not a card. Three columns on a shared first baseline, so the figure and the borough sit on the museum's own line. Case does the sorting — everything categorical is small caps, everything read is mixed case.

            The name is a button — selecting a museum puts it on the map — and the outbound link is a second, separate action beside it. The row is deliberately not a button that contains a link. The link's underline is transparent at rest so a list of 107 stays calm, and appears when the row is hovered. Resting, hovered, peeked (its pin is under the cursor) and selected, below.
