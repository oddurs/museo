The design system, and a specimen of the type it is set in.

Every specimen below is rendered by system.css and components.css and measured at runtime — the contrast ratios are computed, not typed. If a specimen looks wrong, the system is wrong, not the page. Back to the index

01 Principles

  1. One

    Systems before screens. The ramp, the scale and the figure sets were settled and measured before a single component was composed. Nothing in app.css holds a raw value; if it does, that is a bug in the system rather than a shortcut in the page.

  2. Two

    One color, and it must earn its place. Cinnabar marks the exhibition bar, the current selection, the pins and focus — the things you act on. It is never decoration, and there is never a second accent.

  3. Three

    Twelve grays, because detail needs range. Hairlines, marks and text each get their own steps. Borrowing one value for two jobs is what makes an interface look approximate.

  4. Four

    Set the type, don't just style it. True small caps, old-style figures in prose, lining tabular figures in columns, the real ordinal glyph. These are the differences between type that is set and text that is typed.

  5. Five

    Rules and whitespace instead of boxes. No radius, no shadow, no gradient, and nothing moves on selection — weight and color carry it.

02 The neutral ramp

Warm, not gray — every step carries the same red-over-blue bias as the paper, so nothing reads as cold against it. Ratios are measured against --paper in the browser. The 4.5:1 line falls between 400 and 500, and that is the hard floor for text.

    03 The primary

    Cinnabar. One hue, four values, used only where something is live: the bar, the selection, the pins, focus, and the underline beneath a link you are about to follow.

        06 Scale

        Eight sizes, spaced by eye rather than by ratio. A strict modular scale put a museum's name and its address too close together; the interval from --size-heading to --size-small is deliberately wider than a ratio would give, and it is the most important one in the system.

        07 Space & rules

        A 4px base — these nine steps are the only spacing values in the system. Five rule weights, so separation can be graded rather than uniform.
