01 — Principles

  1. One

    Achromatic without exception. Black, white, and four grays. Color is never used to encode meaning, so nothing in the interface depends on it — including the map, whose tiles are desaturated to join the system.

  2. Two

    Type carries the hierarchy. Size, weight and case do the work that color, fills and shadows do elsewhere. Whitney was drawn for the Whitney Museum's wayfinding; it is used here the way signage uses it.

  3. Three

    Rules and whitespace instead of boxes. No border radius, no shadow, no gradient. Structure is drawn with hairlines and the space between things.

  4. Four

    Nothing moves that doesn't have to. Transitions are 120ms and linear, limited to color and background. Selection changes weight, never position.

02 — Color

Seven values, no hue. The ratio given is contrast against paper; anything below 4.5:1 is barred from carrying text, which leaves --ink-quiet for borders and marks alone.

    03 — Families

    Three cuts of one typeface. The rule for choosing between them is a size threshold, not a preference.

    04 — Type scale

    Seven sizes, spaced by eye rather than by ratio — a strict modular scale put the name and its address too close together. The gap from 21px to 13px is the important one, and it is deliberately larger than a ratio would give. Each primitive sets family, size, weight, leading and tracking together; compose with these rather than setting font properties by hand.

    05 — Space

    A 4px base. These eight steps are the only spacing values in the system.

      06 — Elements
